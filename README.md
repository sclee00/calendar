# 연안부두 낚시배 빈자리

인천 연안부두 20인승 낚시배 16척(루키나·동양낚시마트·칸피싱·제일바다낚시)의 날짜별 빈자리와 인천 물때·고저차를 한 달 단위 캘린더로 보여줍니다.

- 웹 캘린더: https://sclee00.github.io/calendar/ (`index.html`)
- 데이터: `data/seats.json`, 물때·고저차: `data/tide.json` (국립해양조사원 자료, 바다타임 인천)
- **확인(수집)은 아이폰에서**: 칸피싱·제일바다낚시는 해외 접속을 막아서 GitHub 서버로는 읽을 수 없습니다. 아이폰의 Scriptable 앱이 한국 통신망으로 네 선사 예약 화면을 직접 읽습니다(`scriptable/fishing.js`). 정해진 시간마다 자동으로 확인하지 않습니다. 실행하면 이번 달부터 설정한 기간(기본 1개월, 앱 안의 '설정'에서 1~12개월)만 확인하고, 캘린더를 그 뒤 달로 넘기면 그 달만 추가로 확인합니다. 네 사이트를 동시에 확인하되 사이트마다 요청은 하나씩 보냅니다.

## 아이폰 설치 (처음 한 번)

1. App Store에서 **Scriptable**(무료)을 설치합니다.
2. Scriptable을 열고 오른쪽 위 **+** 를 눌러 새 스크립트를 만듭니다.
3. 위쪽 제목을 눌러 이름을 **낚시배예약현황** 으로 바꿉니다(웹의 '지금 확인' 버튼이 이 이름으로 찾습니다).
4. `scriptable/loader.js` 내용을 그대로 붙여 넣고 **Done**.
5. 스크립트를 한 번 눌러 실행합니다. 캘린더가 뜨고 위쪽에 "확인 중"이 표시된 뒤 새 결과로 바뀝니다.
6. (선택) 처음 실행할 때 "웹 캘린더에도 올릴까요?"가 나옵니다. GitHub 토큰을 넣으면 확인 결과가 웹 캘린더에도 반영됩니다. 아이폰에서만 볼 거면 '아이폰에서만'.
7. 홈 화면 아이콘: 스크립트를 길게 눌러 Share → **Add to Home Screen**.

### GitHub 토큰 만들기 (웹 반영을 원할 때만)

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
- Repository access: **Only select repositories** → `calendar`
- Permissions → Repository permissions → **Contents: Read and write**
- 만들어진 `github_pat_…` 값을 복사해 Scriptable 첫 실행 때 붙여 넣습니다(아이폰 키체인에만 저장됨).
- 나중에 넣거나 바꾸려면 Scriptable에서 스크립트를 다시 만들 필요 없이, 키체인 항목을 지우는 짧은 스크립트로 `Keychain.remove("fishing_github_asked")`를 실행한 뒤 다시 실행하면 됩니다.

## 앱을 닫아 둔 동안 자동 확인 (단축어 자동화)

정해 둔 시각마다 앱을 열지 않고 확인합니다.
- 결과를 저장해 두어서, 다음에 앱을 열면 바로 보이고 다시 확인하지 않습니다(30분 이내 결과일 때).
- 빈자리 알림을 켜 두었으면 그 조건으로 알립니다.
- 꺼 두었으면 새로 생긴 자리(취소로 다시 열림·새로 열림)를 알립니다.

1. **단축어** 앱 → 아래 **자동화** → **+** → **특정 시간**을 고르고, 시각(예: 오전 7시)과 **매일**을 정합니다. **즉시 실행**을 고르고 **다음**.
2. **새로운 빈 자동화** → 동작 추가에서 **Scriptable**의 **Run Script**를 고릅니다.
3. Script를 **낚시배예약현황**으로 고르고, 동작을 펼쳐 **Run In App(앱에서 실행)**을 **끕니다**.
4. 하루에 여러 번 확인하려면 시각을 바꿔 자동화를 더 만듭니다(예: 7시·12시·18시·22시).

- 홈 화면 아이콘용 단축어는 그대로 **Run In App을 켠 상태**여야 합니다(꺼져 있으면 화면 없이 확인만 하고 끝납니다).
- 확인 범위는 앱 설정의 "처음 열 때 확인할 기간"을 따릅니다.

## 빈자리 알림 (선택, 켜고 끄기)

내가 확인하지 않아도 정해 둔 간격으로 조건에 맞는 날짜만 확인하고, 자리가 생기면 아이폰 알림을 보냅니다.

1. 앱(Scriptable)에서 캘린더를 열고 **설정** → **빈자리 알림**을 켭니다.
2. 확인 간격(30분~48시간)을 고르고, 알림 종류 세 가지를 **각각 따로** 켜고 조건(날짜·요일·남은 자리·어종·배)을 정한 뒤 **알림 설정 저장**.
   - **취소로 다시 열린 자리**: 마감됐던 배에 자리가 다시 생기면 (캘린더에선 천천히 깜빡임)
   - **아직 안 열렸다가 새로 열린 예약**: 예약을 받지 않던 날에 예약이 열리면 (빠르게 깜빡임). 예: 날짜를 내년 4월, 배를 하나로
   - **빈자리 있음**: 조건에 맞는 빈자리가 있으면
   - **알림·깜빡임 미리보기**를 누르면 캘린더에 깜빡임 예시가 붙고, 5초 뒤 아이폰 알림 예시 3개가 옵니다.
3. 홈 화면을 길게 눌러 **+** → **Scriptable** 위젯(작은 크기)을 추가합니다.
4. 추가한 위젯을 길게 눌러 **위젯 편집** → Script를 **낚시배예약현황**으로 고릅니다.
5. 처음 알림을 보낼 때 알림 허용을 물으면 **허용**을 누릅니다.

- 위젯이 새로 고쳐질 때마다 확인합니다. iOS가 새로 고치는 시점을 정하므로 간격은 "최소 간격"이고 조금 늦어질 수 있습니다.
- 같은 자리는 한 번만 알리고, 다시 마감됐다가 열리면 다시 알립니다.
- 끄려면 설정에서 빈자리 알림을 끄고 저장하거나, 위젯을 지웁니다.
