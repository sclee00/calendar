# 연안부두 낚시배 빈자리

인천 연안부두 20인승 낚시배 16척(루키나·동양낚시마트·칸피싱·제일바다낚시)의 날짜별 빈자리와 인천 물때·고저차를 한 달 단위 캘린더로 보여줍니다.

- 페이지: `index.html` (GitHub Pages)
- 데이터: `data/seats.json` — GitHub Actions가 1시간마다 `scripts/scrape.mjs`로 네 선사 예약 화면을 읽어 갱신
- 물때·고저차: `data/tide.json` (국립해양조사원 자료, 바다타임 인천)
- 수동 실행: Actions 탭 → "빈자리 업데이트" → Run workflow
