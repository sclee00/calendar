# 낚시배 빈자리 — PC 버전

아이폰 버전과 같은 캘린더를 PC에서 씁니다.
- Claude나 GitHub를 거치지 않습니다. 이 PC의 한국 인터넷으로 네 선사 예약 화면을 직접 읽습니다.
- 칸피싱·제일바다낚시의 해외 접속 차단에도 걸리지 않습니다.

## 설치·실행 (Windows)
1. [Releases](https://github.com/sclee00/calendar/releases/latest)에서 **fishing-seats.exe**를 받습니다.
2. 아무 폴더(바탕화면 등)에 두고 더블클릭합니다.
   - 처음에는 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요. 서명하지 않은 프로그램이라 뜨는 안내입니다.
3. 기본 브라우저에 캘린더가 열리고, 설정한 기간(기본: 이번 달)을 한 번 확인합니다.

다른 PC에서도 exe만 복사해서 실행하면 됩니다. 확인 결과와 설정은 PC마다 따로 저장됩니다.

Mac은 `fishing-seats-mac-apple`(M1 이후) 또는 `fishing-seats-mac-intel`을 받습니다. 터미널에서 다음을 한 번 실행한 뒤, 같은 방법으로 실행합니다.
```
chmod +x 파일이름
xattr -d com.apple.quarantine 파일이름
./파일이름
```

## 쓰는 법
- **지금 확인**: 설정한 기간을 다시 확인합니다.
- **달 넘기기**: 아직 확인하지 않은 달로 넘기면 그 달만 확인합니다.
- **⚙ 설정**에서 두 가지를 정합니다.
  - 처음 열 때 확인할 기간 (1~12개월)
  - 빈자리 알림
    - 켜 두면 **캘린더 탭이 열려 있는 동안만**, 정해 둔 간격으로 조건에 맞는 날짜를 확인합니다.
    - 맞는 자리가 생기면 데스크톱 알림을 띄웁니다.
    - 알림 종류 세 가지를 각각 켜고, 종류마다 조건(날짜·요일·남은 자리·어종·배)을 따로 정합니다.
      - **취소로 다시 열린 자리**: 마감됐던 배에 자리가 다시 생기면
      - **아직 안 열렸다가 새로 열린 예약**: 예를 들어 날짜를 내년 4월, 배를 하나로 정해 두면 그 배가 4월 예약을 받기 시작할 때. 켜거나 조건을 바꾼 직후 첫 확인은 지금 상태만 기억합니다.
      - **빈자리 있음**: 조건에 맞는 빈자리가 있으면
    - **알림·깜빡임 미리보기**로 알림 모양과 깜빡임을 미리 볼 수 있습니다.
- 자동으로 반복 확인하지 않습니다. 알림을 켰을 때만 정해 둔 간격으로 확인합니다.
- **종료**: 캘린더 탭을 닫으면 몇 분 뒤 프로그램도 스스로 끝납니다. 다시 쓰려면 exe를 다시 실행하세요.

## 참고
- 저장 위치
  - Windows: `%APPDATA%\fishing-seats-pc`
  - Mac: `~/Library/Application Support/fishing-seats-pc`
- 물때·고저차 표는 2027년 10월까지 들어 있습니다.
- 이 PC 버전은 결과를 웹 캘린더(GitHub)에 올리지 않습니다.

## 만들기 (개발용)
`pc/build.sh`를 실행합니다. Go 1.22 이상과 Python 3이 필요합니다.
- 캘린더 화면(`index.html`)을 복사해 PC용으로 고칩니다.
- `pc/dist/`에 Windows·Mac 실행 파일을 만듭니다.
